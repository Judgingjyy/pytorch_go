## 🔑 贯穿全书的核心思想

### 1. 机器学习三步骤框架
李宏毅老师将机器学习统一为三步：
1. **写出带有未知参数的函数**（定义模型架构）
2. **定义损失**（衡量函数的好坏）
3. **优化**（找使损失最小的参数）

这一框架贯穿全书，从最简单的线性模型到Transformer、GAN、强化学习都适用。

### 2. 从"专用"到"通用"的架构进化
```
全连接网络 → CNN(图像) → RNN(序列) → Self-Attention → Transformer(通用)
```
现代深度学习的核心架构Transformer融合了自注意力机制，取代了RNN成为序列建模的主流。

### 3. 预训练-微调范式
BERT和GPT开创的范式：在海量无标注数据上预训练 → 在下游任务上微调。ChatGPT更进一步：预训练 → 监督微调(SFT) → 强化学习(RLHF)。

### 4. 对抗思想的应用
对抗训练（一个网络生成，一个网络判别）不仅是GAN的核心，还在领域自适应（第13章）中得到应用。对抗攻击（第12章）则揭示了神经网络的脆弱性。

### 5. 终身学习的挑战
灾难性遗忘是深度学习走向通用人工智能必须克服的障碍。

## 📖 各章知识点速查

### 第1章：机器学习基础
- **核心问题**：机器学习就是让机器具备"找一个函数"的能力
- **线性模型**：`y = wx + b`，通过梯度下降找最优参数
- **分段线性曲线**：用 Sigmoid/ReLU 函数叠加逼近任意函数
- **三大步骤**：定义函数 → 定义损失 → 优化

### 第2章：实践方法论
- **训练不佳诊断**：模型偏差 vs 优化问题 vs 过拟合
- **模型偏差**：模型灵活性不够 → 增加复杂度
- **优化问题**：梯度下降卡住 → 调整学习率/优化器
- **过拟合**：训练好测试差 → 正则化/数据增强/早停
- **交叉验证**：划分训练/验证集评估泛化能力
- **不匹配**：训练和测试数据分布不同

### 第3章：深度学习基础
- **临界点**：局部极小值 vs 鞍点 → Hessian矩阵判断
- **批量大小**：大批量训练稳定但泛化差，小批量噪声大但泛化好
- **动量法**：模拟物理动量，帮助跳出局部极小值
- **Adam优化器** = RMSProp + Momentum
- **学习率调度**：预热 + 衰减
- **Softmax分类**：输出概率分布，配合交叉熵损失
- **批量归一化(BN)**：加速训练、减少内部协变量偏移

### 第4章：卷积神经网络
- **感受野**：每个神经元只关注局部区域（局部连接）
- **共享参数**：不同位置的感受野共享同一组权重
- **汇聚(Pooling)**：下采样降低计算量和位置敏感度
- **CNN本质**：针对图像的归纳偏置——平移不变性

### 第5章：循环神经网络
- **RNN核心**：通过隐藏状态在时间步间传递信息
- **LSTM**：通过遗忘门、输入门、输出门解决长程依赖
- **梯度消失/爆炸**：RNN的致命弱点——反向传播时梯度连乘
- **双向RNN**：同时考虑上下文信息
- **应用**：序列分类、序列标注、Seq2Seq

### 第6章：自注意力机制
- **核心公式**：`Attention(Q,K,V) = softmax(QK^T/√d)·V`
- **Q/K/V**：查询(Query)、键(Key)、值(Value)三个矩阵来自同一输入
- **多头注意力**：并行使用多组Q/K/V捕捉不同关系
- **位置编码**：为自注意力注入位置信息
- **自注意力vsCNN**：CNN是小范围自注意力的特例
- **自注意力vsRNN**：无序列依赖，可完全并行

### 第7章：Transformer
- **架构**：编码器 + 解码器，均基于自注意力
- **编码器**：自注意力 → 残差+LN → 前馈网络 → 残差+LN
- **解码器**：掩码自注意力 + 编码器-解码器注意力
- **自回归生成**：逐token生成，当前输出作为下一步输入
- **训练技巧**：束搜索、复制机制、计划采样
- **应用**：机器翻译、语音识别、文本生成、ChatGPT的基础

### 第8章：生成模型(GAN)
- **GAN双人博弈**：生成器(G) vs 辨别器(D) —— 造假的vs鉴定的
- **训练方式**：交替训练D和G
- **JS散度问题**：当PG和Pdata无重叠时JS散度恒为log2，无训练信号
- **WGAN**：用Wasserstein距离替代JS散度，需Lipschitz约束
- **Conditional GAN**：G和D都接收条件输入
- **Cycle GAN**：循环一致性损失实现无配对图像风格迁移

### 第9章：扩散模型
- **核心思想**：逐步去噪——从纯噪声出发，一步一步"清理"出清晰图像
- **前向过程**：给真实图像逐步加噪→纯噪声（制造训练数据）
- **反向过程**：噪声预测器逐步去噪→生成图像
- **噪声预测器**：预测噪声而非直接预测图像——更简单的任务
- **文本条件**：噪声预测器接收文本描述作为额外输入
- **代表作**：DALL-E、Imagen、Stable Diffusion

### 第10章：自监督学习
- **定义**：从数据自身构造标签——无需人工标注
- **BERT**：Transformer编码器 + 填空任务(MLM)
- **GPT**：Transformer解码器 + 预测下一个token
- **BERT使用**：预训练→微调（情感分析、词性标注、问答…）
- **BERT为何有效**：产生上下文相关的词向量
- **GPT的In-Context Learning**：Few-shot/One-shot/Zero-shot「无需梯度下降」
- **跨语言迁移**：多语言BERT学到语言无关的表征

### 第11章：自编码器
- **结构**：编码器压缩→瓶颈→解码器重建
- **训练目标**：输入与重建尽可能接近（重建损失）
- **去噪自编码器**：输入加噪声，目标为干净图像
- **特征解耦**：分离不同属性的维度（如内容vs说话人）
- **VQ-VAE**：引入可学习码本实现离散表征
- **其他应用**：压缩、生成、预训练

### 第12章：对抗攻击
- **对抗样本**：人眼不可察觉的扰动导致模型错判
- **FGSM**：单步符号梯度攻击 `x'=x+ε·sign(∇L)`
- **白盒vs黑盒**：黑盒攻击可通过代理网络实现
- **物理攻击**：特制眼镜骗过人脸识别、路标贴纸误导自动驾驶
- **防御-被动**：模糊、压缩、生成器重建等预处理
- **防御-主动(对抗训练)**：用对抗样本训练增强鲁棒性
- **核心矛盾**：攻击比防御容易得多

### 第13章：迁移学习
- **领域偏移**：训练集和测试集分布不同 → 模型失效
- **领域自适应**：有目标域无标注数据时的适配方法
- **核心方法**：领域对抗训练——特征提取器对抗领域分类器
- **领域泛化**：连目标域数据都看不到时的泛化
- **测试时训练**：在测试样本上做自监督学习适配

### 第14章：强化学习
- **核心循环**：环境给观察→智能体出动作→环境变→给奖励
- **Policy Gradient**：用加权交叉熵，权重=动作评价值A
- **五种评价标准演进**：
  - V0即时奖励→V1累积→V2折扣累积→V3减基线→V4优势函数
- **Actor-Critic**：Actor出动作，Critic评价值
- **TD vs MC**：时序差分（可在线学习）vs 蒙特卡洛（需完整回合）

### 第15章：元学习
- **定义**：学会如何学习——让机器自己学出最佳超参/初始化/架构
- **三步**：定义学习算法→定义损失(跨任务)→优化
- **MAML**：学习一个好的初始参数使只需少量梯度步就适应新任务
- **NAS**：用RL或进化算法搜索最优网络架构
- **支撑集vs查询集**：元学习在训练任务的"测试集"上计算损失

### 第16章：终身学习
- **灾难性遗忘**：学新任务后旧任务性能断崖式下跌
- **评价**：最终准确率 + 后向迁移
- **解法1(正则化)**：重要参数给大惩罚项——选择性突触可塑性
- **解法2(梯度约束)**：GEM——新梯度不与历史梯度冲突
- **当前局限**：仅能处理"同类任务不同域"，不能跨领域

### 第17章：网络压缩
- **剪枝**：移除不重要参数/神经元；「彩票假说」——大网含小幸运子网
- **知识蒸馏**：教师网络→学生网络，温度T放大类间关系
- **参数量化**：32bit→8bit甚至1bit(-1/+1)
- **深度可分离卷积**：标准卷积的1/9参数量
- **动态计算**：简单样本走浅层/窄网络，困难样本走深层/宽网络
- **组合使用**：五种技术可叠加获得更大压缩比

### 第18章：可解释性AI
- **显著性图**：`∂loss/∂x`反映各像素对决策的影响
- **SmoothGrad**：对加噪图像求梯度取平均，降噪
- **梯度饱和问题**：梯度为零不代表不重要（如象鼻长度）
- **滤波器可视化**：梯度上升找最大化某滤波器激活的输入
- **类可视化**：用生成器约束产生可解释的类代表图像
- **LIME**：用简单线性模型局部近似复杂模型的行为
- **「聪明汉斯」类比**：模型可能学到虚假关联而非真实特征

### 第19章：ChatGPT
- **本质**：输入对话历史→输出下一个token的概率分布→采样→循环
- **三大误解澄清**：①不是人工预设回复 ②生成时不联网 ③不是搜索
- **技术三阶段**：预训练(海量文本)→监督微调(人工范例)→RLHF(人类打分)
- **GPT演进**：GPT-1(117M)→GPT-2(1.5B，涌现问答能力)→GPT-3(175B)
- **提示工程**：如何"催眠"ChatGPT获得期望行为
- **神经编辑**：精准修改知识而不产生副作用
- **机器反学习**：让模型"遗忘"不应学到的信息

### 第20章：ICLR 2025 Oral —— LS-Imagine
- **任务**：单张3090显卡，纯视觉玩Minecraft
- **核心创新**：长短期世界模型——既能单步也能跳跃式想象
- **功用性图**：用MineCLIP评估图像各区域与任务的关联度
- **跳越机制**：识别远距离目标时跳过中间步直接"传送"
- **关键结果**：砍树80.6% vs DreamerV3 53.3%
- **启示**：巧妙利用预训练视觉语言模型引导探索
